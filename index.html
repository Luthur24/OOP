What is this?

Most educational applications store their content in databases and render it through procedural UI components. They teach a subject, but their structure bears no relationship to the subject itself.

This application is different. It is an artifact designed to teach Object-Oriented Programming (OOP) through an interactive quiz. However, the true pedagogical value lies beneath the surface: the application itself is constructed using rigorous OOP principles.

The questions you answer are instances of an encapsulated Question class. The quiz flow is orchestrated by an EventEmitter-derived QuizEngine. Timer mechanics are an expression of polymorphism via TimedQuizEngine. The AI chat is powered by an encapsulated MistralClient. To study the codebase is to study the curriculum.

This app was built as a SIWES supervisor assignment demonstrating all four pillars of OOP — Encapsulation, Abstraction, Inheritance, and Polymorphism — plus the Singleton and Observer design patterns.

The Architecture

A mapping of class implementations to their demonstrated OOP pillars.

EE

EventEmitter

Abstraction

An abstract base class providing a common pub/sub mechanism. Hides the internal Map<string, Set<Function>> behind a simple interface: on(), off(), emit(), once(). Cannot be instantiated directly — only extended.

Q

Question

Encapsulation

Bundles question data and behavioral logic. The correctIndex and _userAnswer properties are private — the outside world cannot read or mutate them directly. Interaction is only through checkAnswer(), enforcing controlled state mutation.

QB

QuestionBank

Singleton + Abstraction

Guarantees a single global point of access via a private constructor and static getInstance() method (Singleton pattern). Abstracts away data initialization, Fisher-Yates shuffling, and category/difficulty filtering.

QE

QuizEngine

Inheritance

Extends EventEmitter, inheriting the full pub/sub system. Encapsulates quiz state (score, current index) as protected properties so subclasses can access but outside code cannot. Emits 'answer', 'next', and 'complete' events.

TQE

TimedQuizEngine

Inheritance + Polymorphism

Inherits core mechanics from QuizEngine. Overrides submitAnswer() and next() to inject timer logic — augmenting parent behavior via super calls without breaking the interface. This is runtime polymorphism.

MC

MistralClient

Encapsulation

Hides the API key, endpoint URL, and HTTP request complexity behind a clean chat(messages) method. The UI never constructs a fetch request directly — it only calls this high-level interface, a textbook example of information hiding.

Source Code Walkthrough

The key classes as they appear in the codebase — annotated for the assignment.

EventEmitter.js — Abstraction

/** * Abstract base class. Cannot be instantiated directly. * Demonstrates: ABSTRACTION — hides listener Map complexity. */ class EventEmitter { #listeners = new Map(); // private field — hidden from subclasses on(event, cb) { /* subscribe */ } off(event, cb) { /* unsubscribe */ } emit(event, ..args) { /* notify all subscribers */ } once(event, cb) { /* subscribe once, then auto-remove */ } }

Question.js — Encapsulation

/** * Demonstrates: ENCAPSULATION — correctIndex is private. * State can only change through checkAnswer(). */ class Question { #correctIndex; // ← PRIVATE: unreadable from outside #userAnswer = null; constructor(id, text, options, correctIndex, explanation, category, difficulty) { this.id = id; this.text = text; this.options = options; this.#correctIndex = correctIndex; // stored privately this.explanation = explanation; this.category = category; this.difficulty = difficulty; } checkAnswer(index) { // ← only way to "submit" an answer this.#userAnswer = index; return index === this.#correctIndex; } get isAnswered() { return this.#userAnswer !== null; } get isCorrect() { return this.#userAnswer === this.#correctIndex; } reset() { this.#userAnswer = null; } }

QuizEngine.js — Inheritance (extends EventEmitter)

/** * Demonstrates: INHERITANCE — extends EventEmitter. * Gets on/off/emit for free. Protects state from outside. */ class QuizEngine extends EventEmitter { _questions; _currentIndex = 0; _score = 0; // protected constructor(questions) { super(); // ← must call parent constructor this._questions = questions; } submitAnswer(index) { const correct = this._questions[this._currentIndex].checkAnswer(index); if (correct) this._score++; this.emit('answer', { correct }); // inherited from EventEmitter return correct; } }

TimedQuizEngine.js — Polymorphism (override)

/** * Demonstrates: POLYMORPHISM — overrides submitAnswer() and next(). * Same method name, different behavior. Calls super to preserve parent logic. */ class TimedQuizEngine extends QuizEngine { #timer = null; #timeRemaining; constructor(questions, timeMs = 30000) { super(questions); // inherit everything from QuizEngine this.#timeRemaining = timeMs; } submitAnswer(index) { // ← OVERRIDE (Polymorphism) this.#stopTimer(); return super.submitAnswer(index); // call parent version } next() { // ← OVERRIDE (Polymorphism) super.next(); // advance index in parent this.#timeRemaining = this.timePerQuestion; if (!this.isComplete) this.#startTimer(); } }
